📖 How to Use User Portal

1

Account & Link Matching

Aapke registered name se match hone wale links hi aapke dashboard me show honge. Security ke liye koi doosra user aapka data nahi dekh sakta.

2

Real-time Stats Monitoring

Aap apne link ke live visits (Today, 24h, 7d) aur Total Reward Claims ko yahan se live track kar sakte hain.

3

Selecting Extension Plan

Apni zaroorat ke hisaab se 7 din, 15 din, 30 din, 90 din ya 1 Year plan card par tap karein. Amount automatic calculate ho jayegi.

4

Payment & 12-Digit UTR Verification

QR code scan karke payment karein. Payment hone ke baad banking app se 12-digit UTR/Ref number copy karke box me daalein aur "Verify Instantly" dabayein. Link turant extend ho jayega!

5

Expiry Alert

Expiry se 3 din pehle timeline bar yellow aur expire hone par red ho jati hai. Time se pehle renew karein taaki link band na ho.

📜 Terms & Guidelines

1. Account Identity: User ka naam registered link owner name se match hona zaroori hai.

2. Genuine UTR Requirement: Fake ya duplicate 12-digit UTR submit karne par account permanently suspend ho sakta hai.

3. Instant Activation: BharatPe automatic verification ke sath link 5 seconds me extend ho jata hai.

4. Refund Policy: Plan activate hone ke baad fees non-refundable hai.
